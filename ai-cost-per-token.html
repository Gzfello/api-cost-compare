How Much Does AI Cost Per Token? Complete Guide

Understanding AI API pricing is essential for any developer. This guide explains everything you need to know.

What is a token?

A token is a chunk of text used to measure AI API usage. Roughly:

  • 1 token = approximately 0.75 words in English
  • 1 token = approximately 4 characters
  • 1,000 words = approximately 1,300 tokens
  • 1 page of text = approximately 1,300-2,600 tokens

How are APIs charged?

Most AI APIs charge per 1 million tokens. You pay separately for:

  • Input tokens: text you send to the model (your prompt)
  • Output tokens: text the model generates (its response)
  • Cached tokens: repeated context (much cheaper, ~10x discount)

Why do prices vary so much?

Prices range from $0.015 to $300 per million tokens (input). Factors:

  • Model complexity (8B parameters vs 1T parameters)
  • Infrastructure (CPU vs GPU vs custom chips)
  • Market positioning (budget vs premium)
  • Region (some providers have regional pricing)

How to save money

  1. Use cheaper models when possible: GPT-4o mini instead of GPT-4o saves 76%
  2. Use caching: If you send the same context repeatedly, cached tokens cost 10x less
  3. Batch requests: More tokens per request = better efficiency
  4. Compare providers: Use API Cost Compare -
  5. Start with budget models: Test with Groq/DeepSeek, upgrade only when needed
